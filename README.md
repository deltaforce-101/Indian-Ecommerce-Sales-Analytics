# Indian E-commerce Sales & Customer Analytics

## Project Overview
An end-to-end analytics project using SQL, Python, Pandas, and Power BI to analyze Indian e-commerce sales and customer data.

## Tools Used
- Excel
- MySQL
- Python
- Pandas
- Matplotlib
- Power BI
- GitHub

## Dataset
- Customers: 1,000 records
- Products: 198 records
- Sales: 10,000 records

Note: This project uses synthetic practice data.

## Project Work
- Cleaned and validated data
- Analyzed sales revenue using SQL
- Identified top-selling products and customers
- Analyzed monthly revenue and state-wise sales
- Created visualizations using Python
- Built an interactive Power BI dashboard

## Key Business Metrics
- Total Revenue
- Total Orders
- Average Order Value
- Revenue by Product Category
- Revenue by State
- Monthly Revenue Trend
- Order Status Distribution
